# User Journeys

Eight end-to-end journey maps. Each covers stages, touchpoints, emotions,
pain points, how VoteAssist India helps, and where it deep-links to
official ECI resources. These are design references, not literal scripts —
exact copy must go through the content review process in
`06-legal-compliance-review.md` before shipping.

Legend for "emotion" — a rough valence per stage (frustrated / anxious /
neutral / relieved / confident) to guide tone-of-voice decisions in
`07-design-system.md`.

---
